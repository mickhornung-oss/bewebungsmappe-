# Michael Hornung - Public Portfolio

Static GitHub Pages portfolio for Michael Hornung.

## Scope

This repository is intentionally limited to the public website:

- `index.html` - public portfolio homepage
- `impressum/` - legal/contact page
- `assets/site.css` - site styling
- `404.html` - fallback page

Private documents are not part of this repository. Do not commit CV files,
certificates, references, transcripts, scans, images of documents, or PDF files.

## Deployment

GitHub Pages serves the repository from:

`https://mickhornung-oss.github.io/bewebungsmappe-/`

Source: `main` branch, root folder.

## Privacy Rule

The `.gitignore` blocks common private document folders and file types. If a
private document was ever committed by mistake, delete it from the working tree
and rewrite the published branch history before relying on the repository again.
